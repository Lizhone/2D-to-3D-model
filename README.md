# 2D to 3D model
AI-powered 2D-to-3D reconstruction with interactive web-based visualization using Three.js and WebGL.

This project converts a 2D image into an interactive 3D model using AI-based image-to-3D generation. Meshy AI generates the 3D model, which is exported in GLB format and displayed in a web-based viewer using HTML, CSS, JavaScript, and Three.js. WebGL enables GPU-based rendering, allowing users to rotate, zoom, and explore the model from different angles. The project demonstrates the integration of AI-based 3D reconstruction with interactive web graphics.
